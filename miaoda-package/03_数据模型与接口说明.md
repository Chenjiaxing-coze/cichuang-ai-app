# 词创AI · 数据模型与接口说明（给秒哒自定义 API 参考）

> 若你希望秒哒生成的 APP **调用我们自己的后端**（而非秒哒自带后端），可把本文件内容作为"自定义 API 接入"说明粘贴进秒哒对话框。
> ⚠️ 重要限制（先看）：秒哒自动生成的前端**无法实现我们自研的 HMAC 签名 + JWT 令牌**。因此下列接口中：
> - **公开接口**（无需登录 / 无需签名）可以被秒哒版调用（如社区帖子列表展示）；
> - **受保护接口**（登录、发帖、同步等需要签名 + 令牌）秒哒版无法跑通，仍由我们自己的原生壳（android/ + backend/）承载。
> 建议秒哒版先做"公开展示 + 本地文案生成"，不要指望它打通账户与同步。

## 数据模型（后端落库，参考）
- users：id, phone_enc(加密), nickname, avatar, method, created_at
- templates：id, category, title, prompt, example（内置 50 条）
- generations：id, uid, input, output, type, created_at
- posts：id, uid, content, tags, likes, comments, created_at
- comments：id, post_id, uid, content, created_at
- refresh_tokens：id, uid, jti, expires_at, revoked（令牌轮换吊销）
- sync_data：uid, key, value, updated_at（云端同步）
- audit_logs：id, uid, action, detail(脱敏), ip, created_at

## 接口清单（后端 `backend/`）
鉴权（需签名+JWT）：
- POST /api/auth/sms/send —— 发短信验证码（公开，需手机号）
- POST /api/auth/sms/verify —— 验证码登录（返回 access/refresh token）
- POST /api/auth/refresh —— 刷新令牌（旧令牌吊销轮换）
- POST /api/auth/logout

提示词 / 模板（部分公开）：
- GET /api/prompts/list —— 模板列表（可公开展示）
- GET /api/prompts/get —— 模板详情

社区（列表公开，写操作需登录+签名）：
- GET /api/community/posts —— 帖子列表（**公开，可给秒哒版做"社区广场"展示**）
- GET /api/community/posts/:id —— 帖子详情（含评论，公开）
- POST /api/community/posts —— 发帖（需登录）
- POST /api/community/posts/:id/like —— 点赞（需登录）
- POST /api/community/posts/:id/comment —— 评论（需登录）

同步（需登录+签名）：
- POST /api/sync/upload / GET /api/sync/download —— 云端同步

## 安全机制（解释为何受保护接口秒哒版跑不通）
- 每个请求需 HMAC-SHA256 签名：`sign = HMAC(method\npath\ntimestamp\nnonce, SIGN_SECRET)`，服务端校验时间戳 ±5min、nonce 防重放。
- 登录后请求带 `Authorization: Bearer <accessToken>`（JWT，2h）。
- 手机号 AES-256-GCM 加密 + 脱敏展示。
- 这些逻辑在我们的原生壳（词创AI_app.html）里已实现；秒哒自动生成的前端不含这些，故只建议它调用公开接口。
