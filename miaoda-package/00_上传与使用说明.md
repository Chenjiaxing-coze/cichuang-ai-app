# 词创AI · 秒哒（Miaoda）适配上传包 使用说明

> 用途：把本压缩包内容用于 **秒哒 miaoda.cn** 生成「词创AI」安卓 APP（快速给朋友试用 / 验证 UI 与需求）。
> 配套认知报告：见上层目录 `秒哒认知与接入报告.md`（含能力边界与签名限制）。

## 这个包里有什么
| 文件 | 给秒哒的用途 |
|------|--------------|
| `01_词创AI_需求文档_PRD.md` | **主上传物**：作为 PRD 文档上传或粘贴进对话框，秒哒会解析并据此生成应用 |
| `04_词创AI_APP源码_词创AI_app.html` | 我们已做好的 H5 内核源码；可在浏览器渲染后**截图**上传给秒哒"照图生成"，复刻深色科技风 UI |
| `02_界面与风格指南.md` | 视觉规范（配色 / 字体 / 布局），让生成结果贴近我们的设计 |
| `03_数据模型与接口说明.md` | 数据结构与接口清单；若想让秒哒版调用我们的后端，参考此文件（注意签名限制） |
| `04_秒哒对话提示词.txt` | **直接复制粘贴**进秒哒对话框的提问/迭代话术 |

## 上传与生成步骤
1. 打开 https://www.miaoda.cn/ ，用百度账号登录。
2. 创建应用 → 选择「**APP（安卓）**」。
3. 上传 / 粘贴（任选组合）：
   - 上传 `01_词创AI_需求文档_PRD.md`（或把内容粘进对话框）；
   - **上传 `04_词创AI_APP源码_词创AI_app.html` 在浏览器渲染后的界面截图**，让秒哒复刻 UI 风格；
   - 也可把 html 本身作为"网页参考"导入。
4. 生成后在线预览；用 `04_秒哒对话提示词.txt` 里的迭代话术微调。
5. 稳定后：「导出安装包 → 安卓打包」→ 下载 APK 发给朋友安装。

## ⚠️ 必须知道的边界（避免白做）
- 秒哒生成的 APP 使用**它自带的托管后端**，**不是我们的 `backend/`**。登录 / 社区写 / 云端同步等**需要 HMAC 签名 + JWT 的接口，秒哒自动前端无法实现**，因此秒哒版主要能跑通"公开展示 + 文案生成（本地/它自己后端）"类功能。
- **秒哒不支持鸿蒙（HarmonyOS）**——鸿蒙版只能靠我们自主的 `harmony/` 工程 + 华为官方云端构建。
- 真正上线、含安全基线（等保二级）与数据主权的版本，以我们**自主开发轨道（android/ + harmony/ + backend/）** 为准。秒哒版仅作快速验证。
