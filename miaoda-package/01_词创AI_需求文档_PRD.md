# 词创AI · 应用需求文档（PRD）

> 可直接上传到秒哒（miaoda.cn）作为 PRD 文档，或粘贴进对话框。

## 一、应用概述
- **名称**：词创AI
- **定位**：面向普通用户的 AI 文案与提示词生成工具（个人开发者作品，**免费、无广告**）。
- **目标平台**：安卓 APP（本次生成目标）；后续考虑鸿蒙、小程序。
- **核心场景**：一句话/主题生成各类文案与 AI 提示词；模板化套用；社区分享；本地优先 + 云端同步。

## 二、核心功能
1. **AI 文案生成**（主功能）：用户输入主题 / 关键词 / 目标平台，生成：
   - 小红书种草笔记（标题 + 正文 + 话题标签）
   - 短视频口播稿（分镜 / 台词）
   - 电商商品标题与卖点详情
   - AI 绘画 / 写作提示词（中英文）
2. **模板库**：内置 **50 个**模板，按场景分类（种草 / 口播 / 带货 / 朋友圈 / 职场 等），一键套用。
3. **我的收藏**：收藏喜欢的生成结果，本地保存。
4. **用户体系**：游客可直接使用；手机号 + 短信验证码登录（预留微信登录）。
5. **社区**：发帖（文字 + 标签）、帖子列表、帖子详情、点赞、评论；内容经关键词审核。
6. **数据与同步**：本地优先（无网络也能用）；登录后一键把本地数据同步到云端，换设备可恢复。

## 三、界面与交互（参考《02_界面与风格指南.md》）
- 深色科技风，霓虹青(#22D3EE) / 霓虹紫(#A855F7) 强调色，卡片化、圆角、轻发光质感。
- 首页：顶部标题 + 搜索 / 主题输入；中部"场景快捷入口"；下方"最近生成 / 推荐模板"。
- 模板页：分类标签 + 模板卡片网格，点选后进入生成表单。
- 生成页：输入区 + 生成按钮 + 结果卡片（可复制 / 收藏 / 重新生成）。
- 社区页：帖子流（卡片）+ 发帖入口；详情页含评论。
- 我的页：登录态、收藏列表、设置（隐私说明、清除本地数据）。
- 底部 Tab 栏：首页 / 模板 / 社区 / 我的；右下角悬浮"+"生成按钮。
- 移动端竖屏适配，兼顾刘海屏与安全区（底部手势条）。

## 四、数据字段（参考《03_数据模型与接口说明.md》）
- 用户：id、昵称、头像、手机号（加密存储、脱敏展示）、登录方式。
- 模板：id、分类、标题、提示词模板、示例。
- 生成记录：id、用户、输入、输出、类型、时间。
- 帖子：id、作者、内容、标签、点赞数、评论数、时间。
- 评论：id、帖子、作者、内容、时间。

## 五、非功能需求
- 离线可用（降级到本地缓存，不白屏）。
- 隐私合规：仅收集必要信息（手机号用于登录，加密 + 脱敏）；提供隐私说明。
- 性能：生成结果秒级返回（依赖模型）；列表流畅滚动。

## 六、验收标准
- 能生成至少 4 类文案；模板可套用；游客可用；手机号可登录；社区可发帖/点赞；离线可用；深色 UI 美观。
