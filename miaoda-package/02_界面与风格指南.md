# 词创AI · 界面与风格指南（给秒哒生成参考）

> 让秒哒生成的界面贴近我们已有的深色科技风设计。可随 PRD 一起上传，或截图 `04_词创AI_APP源码_词创AI_app.html` 给秒哒"照图生成"。

## 配色（深色背景 + 霓虹强调）
| 角色 | 色值 | 用途 |
|------|------|------|
| 背景主色 | `#081A2B` → `#0F2940`（顶部到中部渐变） | 页面底色 |
| 卡片背景 | `rgba(255,255,255,0.04~0.06)` + `1px` 半透明描边 | 卡片 |
| 霓虹青 | `#22D3EE` | 主强调、按钮渐变起点、链接 |
| 霓虹紫 | `#A855F7` | 强调、按钮渐变终点、图标 |
| 成功绿 | `#10B981` | 成功态、标签 |
| 琥珀 | `#F59E0B` | 提醒 |
| 危险红 | `#EF4444` | 错误 |
| 微信绿 | `#07C160` | 微信登录按钮 |
| 文字主色 | `#E6F0FA` | 正文 |
| 文字次色 | `#9FB4C9` | 辅助说明 |

## 字体
- 优先：`PingFang SC` / `HarmonyOS Sans SC` / `Microsoft YaHei` / 系统默认无衬线。
- 等宽（代码/提示词）：`SF Mono` / `Menlo` / `Consolas`。

## 视觉质感
- 卡片：圆角 `16~18px`，半透明描边，轻投影；主按钮加 `0 8px 24px -10px rgba(34,211,238,.6)` 类发光阴影。
- 强调元素（图标、激活态）可用霓虹渐变 + 轻微 glow。
- 动效克制：悬浮微位移、淡入即可，避免花哨。

## 布局（移动端竖屏）
- 顶部：应用名「词创AI」渐变标题 + 搜索/主题输入框。
- 首页：场景快捷入口（图标 + 文字，2~4 列网格）→ 最近生成 / 推荐模板横向卡片。
- 模板页：顶部分类标签（横向滚动）+ 模板卡片网格（2 列）。
- 生成页：输入区（多行）→ 生成按钮（霓虹渐变、全宽）→ 结果卡片（可复制 / 收藏 / 重生成）。
- 社区页：帖子流（卡片：作者头像 + 内容摘要 + 点赞/评论数）；右下悬浮"发帖"按钮。
- 我的页：头像 + 昵称 + 登录按钮（未登录）/ 收藏列表 + 设置入口。
- 底部 Tab 栏：首页 / 模板 / 社区 / 我的；右下角悬浮"+"生成按钮。
- 安全区：底部 Tab 与悬浮按钮需避让系统底部手势条（`env(safe-area-inset-bottom)`）。
